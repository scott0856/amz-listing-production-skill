# Amazon US Listing 制作 Skill

亚马逊美国站 Listing 制作技能（v3.1.2），「美国站 01-10 运营工作流」的第 6 步：承接第 5 步供应链开发（精确报价 / 样品确认 / BOM 清单），输出可用于上架的 Listing 资产。

## 它解决什么问题

把「文案 + 7 图规划 + 视频脚本 + A+ 结构 + AI 生图提示词 + 合规检查」收在一份可执行的规范里，避免设计师凭感觉出图、运营凭经验写词，最后在合规和转化上一起踩坑。

## 覆盖范围

| 模块 | 内容 |
|---|---|
| 标题 | 关键词驱动的标题公式、字符控制、A/B 测试方案 |
| 五点描述 | 层级结构、Alexa for Shopping 问答映射、合规红线 |
| 图片 | 7 图规划表（每张图对应一个买家问题）、主图硬指标、移动端 300px 可读性检查 |
| 视频 | 15–60 秒脚本结构、技术规格、3D 动画方案 |
| A+ | 标准 / Premium 模块选择、埋词策略 |
| 后台搜索词 | 含西班牙语本地化 |
| **AI 生图** | 产品真值表 → 垫图筛选 → JSON 结构化提示词 → 图片合规检查 |
| 迭代 | 30 天优化周期、数据监控看板 |

## AI 生图部分的核心设计

1. **产品真值表**：把产品形态、尺寸、材质、颜色（Pantone/RGB）、纹理、使用步骤、「不能画错 / 不能乱写」固化成一份"宪法"，数据继承自第 5 步的 BOM 与样品确认单。
2. **垫图筛选**：按图位定义参考图要求（主图要白底、材质图要微距），并做「垫图—真值表」一致性检查。
3. **JSON 结构化提示词**：不只写"要什么"，同时写 `forbidden` 清单，明确禁止改变形态、虚构功效、出现竞品元素。
4. **合规检查**：单图 10 项 + 套装 5 项 + 与实物比对，覆盖分辨率、白底、文字可读性、色彩偏差、认证徽章等。

## 使用方式

本仓库只有一个 `SKILL.md`，把它放进你的 Agent Skills 目录即可（Claude Code / Codex / Cursor 等支持 Skills 格式的环境），也可以直接作为人读的作业规范使用。

```
<skills-dir>/amz-listing-production-skill/SKILL.md
```

## 依赖与边界

- 上游数据（关键词库、BOM、样品确认单）来自本工作流第 3–5 步；单独使用时需要自行提供等价输入。
- 原技能在完整工作流中会调用 Sorftime MCP 获取关键词数据；**纯作图环节不依赖 MCP**。
- 本 Skill 产出的是**生产规范与提示词**（JSON 生产单），不直接生成图片。出图需配合生图工具或执行型 Skill。
